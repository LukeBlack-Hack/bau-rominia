Datenschutz

Das ist ein Entwurf. Anfragen, Konten und Kalkulationen bleiben nur in diesem Browser und werden nicht an einen Server geschickt. Das Passwort wird als Hash abgelegt. Die Entwicklung sieht in diesem Browser die angelegten Konten, ohne das Passwort und ohne den Authenticator-Schlüssel. Ein neues Passwort gibt es nur mit dem Code aus der App oder einem Notfallcode.

Sobald ein richtiger Versand dazukommt, braucht die Seite eine vollständige Datenschutzerklärung mit Zweck, Speicherdauer und Verantwortlichem.
